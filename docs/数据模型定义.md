# 档案资政案例管理与展示平台 — 数据模型定义

> 文档 2/3 | 版本 v1.0 | 2024-06-10
> **⚠️ 本文档为设计阶段数据模型规格。实际数据库 DDL 位于 `server/migrations/001_init.sql`（25 张表，已实施），但 Redis 缓存（§4）和 Elasticsearch 索引（§5）为规划建议，暂未实施。**

## 1. 概述

本文档定义系统的数据库结构。推荐使用 PostgreSQL（支持 JSONB、全文搜索、角色行级安全），辅以 Redis 做缓存和会话管理，Elasticsearch 做全文搜索。

---

## 4. Redis 缓存设计

| Key 模式 | 数据类型 | TTL | 用途 |
|----------|----------|-----|------|
| `session:{token}` | String (JSON) | 24h | 用户会话 |
| `captcha:{captchaId}` | String | 5min | 验证码 |
| `portal:hero` | String (JSON) | 10min | 首页统计 |
| `portal:announcements` | String (JSON) | 5min | 公告列表 |
| `user:{id}:prefs` | Hash | 1h | 用户偏好 |
| `hot:topics` | Sorted Set | 30min | 热门专题排序 |
| `rate_limit:{ip}:{endpoint}` | String (计数) | 1min | 限流计数器 |

## 6. 文件存储方案

- 案卷附件、报告全文、文献原文 → **MinIO / 阿里云 OSS / S3 兼容存储**
- 用户头像 → 同上，或使用 DiceBear / Gravatar 生成
- 文件访问 URL 均使用预签名 URL（有效期 1h）
- 支持的文件类型: PDF, DOCX, XLSX, CSV, JSON, XML, JPG, PNG
- 单文件限制: 50MB
